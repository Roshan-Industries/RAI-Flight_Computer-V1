# FC_V1 Firmware

This directory contains firmware developed for Flight Computer V1.

## Final Firmware
The frozen firmware used for final bench validation is:

`01_Final/FC_V1_v1.6.5_ButtonIntegrated.ino`

Status: FROZEN / FINAL  
Validation: 5/5 integrated bench-test sequences passed

## Directory Structure
- `01_Final` — final validated firmware
- `02_Development` — component tests, integrated tests and previous revisions
- `03_Libraries_and_Dependencies` — dependency information
- `04_Firmware_Documentation` — pin map, state machine, parameters and revision history

FC_V1 is an experimental bench-validated prototype and is not flight-qualified hardware.
