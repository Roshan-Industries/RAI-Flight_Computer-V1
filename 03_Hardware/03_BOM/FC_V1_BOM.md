# FC_V1 Prototype Bill of Materials

## Principal Components

| Component | Quantity | Function |
|---|---:|---|
| ESP32 Development Board | 1 | Main processing |
| BMP280 Module | 1 | Barometric pressure / relative altitude |
| MPU6050 Module | 1 | Inertial sensing |
| 0.96" SSD1306 OLED | 1 | Local diagnostic interface |
| SG90 Micro Servo | 1 | Recovery-actuation demonstration |
| Momentary Push Button | 1 | ARM / DISARM / RESET |
| Status LEDs | 4 | Visual status indication |
| Buzzer | 1 | Audible recovery indication |
| Perfboard | 1 | Prototype integration |
| Female Headers | As required | Removable module mounting |
| Screw Terminals | As required | External connections |
| Resistors | As required | LED current limiting |
| Hook-up Wire | As required | Point-to-point interconnection |
| Header Pins | As required | Module interfaces |

## BOM Classification

This is a prototype-level engineering BOM.

The components were selected primarily for:

- availability;
- development accessibility;
- functional suitability;
- ease of integration;
- cost.

The BOM does not represent a production or flight-qualified configuration.
